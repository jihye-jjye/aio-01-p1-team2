# AI_JOB_COACH 개발 계획서 — 현재 상태 반영 수정본

## 우선순위 작업

### 1단계: 현재 main 안정화

1. `backend_user/app/routers/auth_router.py`의 `auth_scheme` import 오류 수정
2. 네 애플리케이션의 독립 실행 여부 확인
3. 환경변수 예제 정리
4. 관리자 테스트 전체 실행 및 실패 수정
5. 샘플 Product·Item 기능 유지·삭제 여부 확정

### 2단계: DB 재현성 확보

1. 실제 Supabase의 `user_accounts`, `profiles` migration 작성
2. `ai_logs`, `admin_log_summary`, `feedback` migration 작성
3. FK·인덱스·RLS·Runtime 권한 문서화
4. 새 Supabase 프로젝트에서 순차 migration 검증

### 3단계: 관리자 핵심 기능

1. 관리자 로그인과 역할 검증
2. 운영 대시보드
3. 사용자 종합 상세, 로드맵·퀘스트 진행률
4. 저장 공고 목록
5. AI 로그·피드백 실데이터 연동
6. 관리자 Streamlit 화면 연결

### 4단계: 사용자 핵심 여정

1. 회원가입·로그인·내 정보
2. 프로필·온보딩
3. 로드맵·퀘스트
4. 공고 검색·저장·변경 제안
5. AI 코치 세션
6. 사용자 Streamlit 화면 연결

### 5단계: 통합·배포

1. 사용자·관리자 권한 경계 테스트
2. 정상·빈 상태·오류·토큰 만료 E2E 테스트
3. API 명세를 OpenAPI와 자동 대조
4. DB migration 재실행 테스트
5. 배포 환경변수·CORS·HTTPS 확인
6. 데모 시나리오와 복구 절차 작성
