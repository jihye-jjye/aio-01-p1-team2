### 주요 UI 요소

| 요소 | 유형 | 설명 |
|------|------|------|
| ❯ 01 로그인 — □ × | 헤더 | 터미널 스타일 창 제목 (핑크 `#ef75cf`) |
| 내 커리어 퀘스트, 이어서 시작! | 타이틀 | 녹색(`#8fe35c`) 강조 |
| 아이디 | Text Input | placeholder "user", 다크 테마 스타일 |
| 비밀번호 | Text Input (password) | Show/Hide 토글 버튼 포함 |
| ❯ 로그인 | Form Submit Button | 핑크 네온 스타일 (`#ff78c5`, 보더 `#e43b99`) |

| 말풍선 + 캐릭터 🧑🏻‍💻 | 장식 | 오른쪽 영역, 환영 메시지 + 이모지 |

### 기능 설명
- 로그인 성공 시 `get_profile()` 호출
  - 프로필 있음 → 대시보드로 이동
  - 프로필 없음 (`PROFILE_NOT_FOUND`) → AI 프로필 분석으로 이동
- 오류 처리: `INVALID_CREDENTIALS`, `CLIENT_TIMEOUT`, `NETWORK_ERROR` 구분
- JWT access + refresh token 저장 (`save_auth_tokens`)
- `remember_login` 상태 저장 (브라우저 복원용)

### 주요 UI 요소

| 요소 | 유형 | 설명 |
|------|------|------|
| 회원가입 | 제목 | `st.title` |
| 계정 정보를 입력해 주세요. | 설명 | `st.caption` |
| 사용자 이름 | Text Input | placeholder "이름을 입력하세요" |
| 아이디 | Text Input | placeholder "예: user", 패턴: `^[a-z0-9._-]{4,50}$` |
| 비밀번호 | Text Input (password) | 8~128자 |
| 비밀번호 확인 | Text Input (password) | 재입력 확인 |
| 회원가입 | Form Submit Button (Primary) | 파란색(`#2563eb`) |
| 로그인으로 이동 | Button (Secondary) | `st.switch_page("app_pages/login.py")` |

### 유효성 검증
- 아이디: 4~50자, 영문 소문자/숫자/점/밑줄/하이픈
- 비밀번호: 8~128자
- 비밀번호 확인: 일치 여부
- 사용자 이름: 필수 입력
- 오류 시 `st.warning` 리스트 표시

### 기능 설명
- 회원가입 성공 시 자동 로그인 및 AI 프로필 분석 페이지로 이동
- 응답에 token 포함 (`save_auth_tokens` 호출)
- `LOGIN_ID_ALREADY_EXISTS` 오류 시 "이미 가입된 아이디입니다." 안내
- `SERVICE_UNAVAILABLE` 등 네트워크 오류 시 "같은 정보로 로그인" 유도

## 04. AI 프로필 분석 (Onboarding)

**파일:** `frontend_user/app_pages/onboarding.py`  
**스크린샷:** `docs/screenshots/user/04_onboarding.png` (프로필이 이미 있는 사용자는 진입 불가, 소스 기반 기술)  
**테마:** Dark Terminal (`#080b16` 배경, 채팅 스타일)

### 3단계 흐름

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 1. 대화 단계 │ ──→ │ 2. 검토 단계 │ ──→ │ 3. 완료 단계 │
│(conversation)│     │  (review)    │     │ (completed)  │
└──────────────┘     └──────────────┘     └──────────────┘
```

### AI가 수집하는 8개 프로필 필드

| 필드명 | 화면 라벨 | 아이콘 | 설명 |
|--------|----------|--------|------|
| `target_role` | 목표 직무 | 🎯 | 희망 직무명 |
| `skills` | 보유 기술 | 🛠️ | 기술 스택 리스트 |
| `experience_summary` | 경험 요약 | 📁 | 자연어 경력 설명 |
| `target_date` | 목표 취업일 | 📅 | YYYY-MM-DD 형식 |
| `target_company` | 희망 기업 | 🏢 | 선호 기업 (선택) |
| `preferred_environment` | 선호 근무 환경 | 🌿 | 근무 환경 선호도 |
| `daily_notification_time` | 알림 시간 | ⏰ | HH:MM 형식 (예: 09:30) |
| `assistant_style` | AI 답변 스타일 | 🤖 | `friendly` 또는 `direct` |

- AI 답변 스타일: `friendly` 또는 `direct`
- 검증 실패 시 확정 버튼 비활성화

### 기능 설명
- Redis 기반 세션 관리 (session_id, revision)
- 대화 중 `send_message()` → AI 응답 수신 → `save_response()` → `st.rerun()`

- 완료 후 추천 공고 페이지 이동 제안
- 프로필 페이지에서 "AI와 전체 프로필 다시 작성하기"로 재진입 가능

## 시스템 공통 사항

### 인증 체계
- JWT (Access Token + Refresh Token)
- `save_auth_tokens()` → 브라우저 Storage 저장
- `restore_auth_from_browser()` → 앱 시작 시 복원 (app.py on_load)
- `is_logged_in()` → `access_token` 유무 확인
- `clear_auth_state()` → 로그아웃, 모든 session_state 초기화

### 에러 처리
- 모든 API 호출은 `BackendAPIError` (code, message, status_code, retryable)
- `UNAUTHORIZED` (401) → 자동 로그아웃
- `PROFILE_NOT_FOUND` → 프로필 생성 유도
- `CLIENT_TIMEOUT` / `NETWORK_ERROR` → 재시도 안내
- 네트워크 오류 시 멱등성 보장 (request_id 기반)
